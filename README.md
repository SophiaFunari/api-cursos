# API de Curso 

API para gerenciamento de **professores** e **cursos**

## Tecnologias 
- JavaScript
- Node JS
- Express
- Mysql
 
    ## Endpoints
  - `POST /professores` - Cria um profssor
  - `GET /professores` - Lista professores
  - `POST /cursos` - Cria cursos
  - `GET /cursos` - Lista cursos
